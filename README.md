# Python Inventory System

A menu-driven inventory management system built progressively across 5 labs for CCGC 5003 — Application Programming at Humber Polytechnic (Summer 2026).

## Features
- Phase 1: Single item input and formatted tabular display
- Phase 2: Multi-item stock with add, display, and search (PrettyTable)
- Phase 3: Sales transactions using Python dictionaries
- Phase 4: File persistence — reading and writing inventory to disk
- Phase 5: Data encryption for secure file storage

## Technologies
Python · PrettyTable · File I/O · Encryption
